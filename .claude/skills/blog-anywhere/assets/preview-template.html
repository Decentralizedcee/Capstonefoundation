5. Where to paste it

Shopify
  1. In Shopify admin go to Online Store then Blog posts, and choose Create blog post.
  2. Paste the Title. In the Content editor either paste the formatted post, or click the <> (Show HTML) button and paste the HTML code.
  3. Add the Excerpt, choose the Blog, add Tags, and set the Featured image with its alt text.
  4. Under Search engine listing choose Edit and paste the Page title, Meta description and URL handle.
  5. Save as Hidden (or a draft), preview it, then set it to Visible.
WordPress
  1. Go to Posts then Add New. Paste the Title.
  2. Paste the formatted post straight into the editor, or add a Custom HTML block and paste the HTML code.
  3. In the post settings set the URL slug, Excerpt, Categories, Tags and the Featured image with alt text.
  4. Paste the SEO title and Meta description into your SEO plugin's boxes (for example Yoast or Rank Math).
  5. Save as draft, preview, then publish.
Wix, Squarespace, Webflow, Ghost or something else
  1. Create a new blog post and paste the Title.
  2. Paste the formatted post into the visual editor. If there is an HTML, code or embed block, you can paste the HTML code there instead. Ghost also accepts Markdown.
  3. Look for the post's SEO or search settings for the title, description and URL slug, and for fields called excerpt, tags and featured image.
  4. Menu names change, so look for the closest match. Save as a draft, preview, then publish.
