# Video Script Format

Only produce these when explicitly asked. Generate **3 variations for
long-form** and **3 variations for short-form** (6 scripts total), each
pulling from the strongest, most-validated ideas surfaced during analysis —
not every idea discussed.

Long-form (e.g. 60-90s+, YouTube/in-feed video) and short-form (e.g. 15-30s,
Reels/TikTok-style) should differ in more than just length: short-form needs a
faster hook and fewer scenes/beats; long-form has room to build a case or tell
a fuller story before the CTA.

## Required structure (use for every script)

```
## Script [N] — [Long-form | Short-form]: [Title]

**Objective:** [What this script is meant to accomplish — e.g. drive donation
signups, build brand awareness for X, retarget site visitors with objection
handling. One sentence.]

**Timed hook (0:00–0:0X):** [The exact opening line(s)/visual described,
tied to a timestamp, that has to earn the next 3 seconds of attention.]

### Scenes

1. **Visual:** [What's on screen]
   **CHARACTER:** [Who's on screen / speaking, if anyone — e.g. "Founder,"
   "UGC creator," "Beneficiary," "None (text-only)"]
   **VOICEOVER:** [Spoken line(s), or "—" if none]
   **TEXT:** [On-screen text/captions, or "—" if none]

2. **Visual:** ...
   **CHARACTER:** ...
   **VOICEOVER:** ...
   **TEXT:** ...

   [Continue numbering scenes through the full script. Long-form scripts
   will typically have more scenes than short-form.]

**CTA:** [The exact closing call to action — spoken and/or on-screen — and
where it sends the viewer.]
```

## Notes on filling it in

- **Title** should be a short working name for the concept, not a generic
  label like "Script 1" (e.g. "Founder Origin Story," "Beneficiary
  Testimonial — Before/After").
- **CHARACTER** should name a role/type, not necessarily a real person's
  name, unless a specific person has already come up in the conversation.
- Every scene needs all four fields present, even if a field is empty for
  that scene — use "—" rather than omitting the field, so the format stays
  scannable for whoever is producing this.
- Ground each script in a specific idea or pattern that came out of the
  week's analysis — reference it briefly in how you introduce the set (e.g.
  "these two scripts build on the competitor's before/after pattern we saw
  earlier this week"), not in the script format itself.
