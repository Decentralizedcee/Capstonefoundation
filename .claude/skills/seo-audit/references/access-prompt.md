# Access prompt (say it in plain words)

"To audit the site I need to know what you have. Tell me yes, no or not sure for each:

1. **A link** to the site. A public address, or a preview link the platform gave you.
2. **Password protection.** Does the site or preview ask for a password? (If yes, I can only see the password page. Do not paste the password here. Ask the client for a public preview link, or I will report only what I can reach.)
3. **The code.** For Shopify that is the theme files. This lets me show fixes on a copy.
4. **Admin access.** A staff account or collaborator access that you connect yourself. Never type a password or key into this chat.
5. **Written permission** from the client to change anything.

You can always say just 'link only'. Then I make a report and change nothing. Each extra thing you have lets me show more that I can fix from our end."

After the answers, state: the mode, what is possible, what is not, and that nothing will be changed without written permission.
